Export Format: BS_YYYYMMDD_CODE

BS = Benthic Survey

### Depth
1. 25m
2. 20m
3. 15m
4. 10m
5. 5m

    From each depth, will be selected 5 pictures per replicate. Total 25 pictures per site if there is 5 depth surveyed. 

### What considered a good benthic picture?
1. Not blurry
2. No obstruction (hand, pointer stick, flashlight)
3. Light evenly distributed, not too many shadow
4. Show the substrate condition
5. Minimum 20% of the picture is coral/algae/rubble

Directory example:
BS_20260406_CG
inside, it is divided into 3 sub folders:
- BS_20260406_CG chosen
- BS_20260406_CG cropped
- BS_20260406_CG reserved

on /BS_20260406_CG/BS_20260406_CG reserved, it is divided into more sub folders based on depth, then 5 best pictures will be taken from each depth then copied into /BS_20260406_CG/BS_20260406_CG chosen which then be copied into BS_20260406_CG/BS_20260406_CG cropped. 

in folder /BS_20260406_CG/BS_20260406_CG cropped, the photos will be cropped into square 1:1 ratio that are exactly match the square of the line of the bruv. No skewed pictures, square according to the bruv line structure. The save option will be save, not save as a copy.
